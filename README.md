# StoryCAD Legacy STBX Conversion Tool



This is a simple tool written in C# using the WinUI3 Framework, if you have any Legacy STBX files this tool will help you convert them.



## What is a Legacy STBX File?

A legacy STBX file is a StoryCAD Outline File that was last saved in prior to StoryCAD 3.0.0, if you have opened your outline in a StoryCAD version that is 3.0.0 or newer then it has been automatically converted and you do not need to use this tool. You should only use this tool if StoryCAD has said your file needs converting.



## Why does my outline need converting?

Starting with StoryCAD 3.3.0 we are dropping support within StoryCAD to automatically convert legacy STBX files as we believe most users have will not be affected by us removing support for Legacy STBX Files.
